# Machine Learning for Earth Systems Modelling

Code examples from ECMWF's Machine Learning for Earth Systems Modelling online courses, run over 2026. Their primary intention is to support the learning in two online courses [Machine Learning for Earth Systems Modelling: Architectures, Data and Prediction](https://learning.ecmwf.int/course/view.php?id=99) (listed as notebooks and supporting documents in the directories m1-m7) and [Machine Learning for Earth Systems Modelling (Applications and Future Directions)](https://learning.ecmwf.int/enrol/index.php?id=100) (listed under the c3 sub-directory). Enrol in these (free) courses for context on the Jupyter notebooks. Also note that the notebooks are not officially supported by ECMWF, and that this repository will be in development while the courses are under construction.
